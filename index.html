Este visualizador não executa a ficha

Você está vendo a página por um visualizador de arquivos — ele desenha o conteúdo, mas não roda o código que monta o treino, salva as cargas e calcula a nota. Por isso os campos aparecem vazios.

No iPhone Não adianta procurar "Abrir no Safari": a Apple bloqueou a abertura de arquivos HTML no navegador. O caminho é publicar o arquivo num endereço na internet e abrir esse endereço no Safari. Serviços como netlify.com, tiiny.host ou GitHub Pages fazem isso de graça — você envia o arquivo e recebe um link. Depois, no Safari, use Compartilhar → Adicionar à Tela de Início.
No Android Toque nos três pontos e escolha Abrir com → Chrome. Funciona direto, sem publicar nada. Depois use os três pontos → Adicionar à tela inicial.
No computador Abra o arquivo normalmente com duplo clique. Windows, Mac e Linux rodam sem restrição.
Se esta mensagem continuar aparecendo dentro de um navegador de verdade, verifique se o JavaScript está ativado.
